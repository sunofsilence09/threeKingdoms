# 三国行旅 H5 Demo

这是一个以流民视角进入三国乱世的叙事 RPG H5 原型。当前切片先验证核心循环：共同序章、点击探索、曹操/孙权/刘备路线选择，以及一场小型战术战斗。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173` 即可游玩。

## 常用命令

```powershell
npm test
npm run build
```

## 当前玩法

1. 在序章面板点击“踏上逃难路”。
2. 点击旧驿道完成伏击，再到枯井村补给，前往临水镇。
3. 进入路线选择，从曹操、孙权、刘备中选择一条路线。
4. 每回合三名队员各有一次移动和一次攻击或守势；移动后仍可攻击相邻敌人。所有队员完成行动后，敌军统一行动。“结束回合”会让其余队员守势。
5. 战斗结束后查看路线影响下的收束文本。

当前画面使用 Phaser 绘制的像素化几何素材，方便先验证交互和节奏；正式美术素材可以在玩法稳定后替换。

曹方增加补给与旅人攻击，孙方增加士气与队伍移动距离，刘方增加士气、体力与守势减伤。路线奖励会累加到已有资源上。

地图和路线进度会自动保存在当前浏览器中。战斗中刷新页面，会从当前战斗开局重新开始；战败后也可以直接重试当前战斗。手机建议横屏游玩。

## 浏览器验证

启动开发服务器后，在已安装 Playwright 和 Chromium 的 Python 环境中运行：

```powershell
python scripts/verify_h5.py
```

脚本通过鼠标或触摸操作完成三条路线的序章、伏击、补给、路线战斗、结局和重新开局，同时检查战败重试、刷新恢复与窄屏布局。截图保存在本地 `artifacts/` 目录。使用其他 Vite 端口时，可设置 `H5_URL` 环境变量。
