# 三国行旅 H5 Demo

这是一个以流民视角进入三国乱世的叙事 RPG H5 原型。当前切片先验证核心循环：共同序章、点击探索、曹操/孙权/刘备路线选择，以及一场小型战术战斗。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173` 即可游玩。

## 常用命令

```powershell
npm test
npm run build
```

## 当前玩法

1. 在序章面板点击“踏上逃难路”。
2. 点击旧驿道完成伏击，再到枯井村补给，前往临水镇。
3. 进入路线选择，从曹操、孙权、刘备中选择一条路线。
4. 每回合三名队员各有一次移动和一次攻击或守势；移动后仍可攻击有效射程内的敌人。所有队员完成行动后，敌军统一行动。“结束回合”会让其余队员守势。
5. 战斗结束后查看路线影响下的收束文本。

当前画面使用 Phaser 绘制的几何素材与像素主角头像，方便先验证交互和节奏；正式美术素材可以在玩法稳定后替换。中文文字使用独立的高清渲染与字形留白，避免缩放后裁字。

主角暂定名为姜垣。地图和战斗中会显示姜垣的角色面板。战斗面板实时显示体力、攻击、移动、所属阵营与行动状态，点击头像可选中主角。手机竖屏时面板移至棋盘下方。

曹方增加补给与姜垣攻击，孙方增加士气与队伍移动距离，刘方增加士气、体力与守势减伤。路线奖励会累加到已有资源上。

地图和路线进度会自动保存在当前浏览器中。战斗中刷新页面，会从当前战斗开局重新开始；战败后也可以直接重试当前战斗。手机建议横屏游玩。

## 浏览器验证

启动开发服务器后，在已安装 Playwright 和 Chromium 的 Python 环境中运行：

```powershell
python scripts/verify_h5.py
python scripts/verify_tactical_ui.py
python scripts/verify_growth_abilities.py
```

脚本通过鼠标或触摸操作完成三条路线的序章、伏击、补给、路线战斗、结局和重新开局，同时检查战败重试、刷新恢复、角色面板数据、中文文字边界与窄屏布局。截图保存在本地 `artifacts/` 目录。使用其他 Vite 端口时，可设置 `H5_URL` 环境变量。


## 流民成长与战棋地形

姜垣以菜刀开局，阿满与陈达使用拳脚。选择阵营后的任务才获得短刀、木枪和猎弓；木枪射程 1–2 格，猎弓射程 2–3 格且不能贴身射击。当前切片保持三名流民，不会开局配备骑兵或重装士卒。

三人独立积累经验：伏击胜利基础经验各 30 点，路线战斗基础经验各 45 点，倒地同伴也能获得胜利经验。初始 1 级、上限 10 级；从当前等级升级需要 `20 + 10 × (等级 - 1)` 点经验，溢出经验保留。每升一级增加 2 最大体力，每两级增加 1 攻击。当前两场战斗可从 1 级升至 3 级，结算显示升级结果；等级、经验和已领奖记录自动保存，失败与重试不发经验，刷新结局不会再次领奖。旧版存档会补齐三人的初始成长数据。

棋盘扩大为 **16×10**。点击“全图”查看完整战场，“放大”查看局部，“归位”定位选中队员；鼠标与触摸均可拖动，鼠标滚轮也可切换缩放。右侧同行名单可切换队员，移动范围用绿点标记，有效攻击目标用红框标记。

- 巨石、倒车和断墙：阻挡移动与攻击视线。
- 河道：不能直接穿越，通过木桥通行；不阻挡射击。
- 树林：每格消耗 2 点移动力，受到远程伤害减少 1，伤害最低为 1。
- 道路和木桥：每格消耗 1 点移动力。

敌军也会绕过障碍，按自身移动力移动后攻击。点击地形可查看说明。手机建议横屏，放大后棋格更便于点击。


## 六维培养、闪避与绝招

每升一级获得 **3 点技能点**，姜垣、阿满、陈达分别培养。每项属性初始为 10，每项上限 30；保留原有等级基础成长，以下加成按超过初始值的投入计算：

| 属性增加 1 点 | 实际能力变化 |
| --- | --- |
| 统率 | 防御 +1，命中伤害最低为 1 |
| 武力 | 攻击 +1 |
| 智力 | 闪避率 +2%，上限 40% |
| 政略 | 每次首次胜利，全队合计额外补给 +1 |
| 魅力 | 该角色的胜利经验 +5%，按整数百分比计算后向下取整 |
| 魄力 | 最大体力 +2 |

点击角色面板的“成长”，或路线/胜利/结尾中的成长入口，可以切换角色并分配。加减按钮修改草稿，实时预览能力，确认后一次保存；取消不扣点，切换角色保留本次草稿。战斗中仅可查看。旧存档会按已有等级补发未分配点数，保留原等级、经验、路线与奖励标记。

每人当前拥有一个绝招，每场战斗限用一次：

- **姜垣 · 绝处逢生**：体力不高于最大体力的一半时可用，回复最大体力的 30%（向上取整、不超过上限），本回合下一击攻击提高 50%。
- **普通角色 · 拼命**：消耗最大体力的 20%（向上取整，至少 1），且不能把自己扣至倒地；本回合下一击攻击提高 50%。普通敌人在半血以下且能够攻击时也可能使用。

发动绝招不消耗移动或攻击机会，但本回合攻击/守势后无法发动。强化不能叠加，攻击后或本方回合结束时消失；闪避也会消耗攻击机会与本次强化，不返还绝招次数或体力。闪避时目标保留守势。骰点使用关卡固定初始种子与本场随机状态，重试相同操作可复现。

战斗右侧显示所选角色的防御、闪避和绝招条件。绝招按钮位于队员名单下方、守势按钮上方；棋子金色三角和角色面板“攻击强化”标明下一击强化，消息区显示闪避与敌方拼命。

## 人物详情与战场外观

主角状态栏和战场队员名单有“详情”按钮，成长面板也能查看当前人物；路线选择页可打开“人物详情”。人物志展示全身立绘、简介、等级经验、六维、装备、战斗能力与绝招，可切换三名伙伴。战斗中的“敌方详情”也能查看山贼；倒地或已行动的单位仍可查看。

战斗详情使用本场实际体力和状态，查看不消耗行动；关闭或按 Escape 返回原界面，保留路线选择和未确认的成长草稿。桌面双栏展示，手机竖屏上下排列并可滚动。

立绘与棋盘小人采用对应的衣色、头带、体型和站姿：姜垣沉稳、阿满侧身探步、陈达宽站护身、头目挺胸抱臂、喽啰缩身警戒。棋盘武器随真实装备变化，配有移动、出手、闪避和绝招反馈；系统偏好减少动态效果时关闭短动画。两名普通山贼共享职业立绘。

图片保存在`public/assets/characters/`，使用内置生图工具生成，新增立绘的最终提示词见`docs/art/2026-10-22-character-portraits.md`。

人物志的“乱世人物”已加入**曹操、刘备、孙权、孙尚香、貂蝉、蔡琰**，每人有独立全身立绘和对应的小人预览。三位主君在阵营选择卡上显示头像与独立详情入口；查看后保留已经选择的路线。

六名新人物目前为可查看角色，显示“尚未同行”以及身份、擅长和随身物件；招募与新剧情尚未接入，当前战场队伍仍为姜垣、阿满、陈达。人物志的小人预览与棋盘共用绘制逻辑，衣色、冠饰、长袍/裙装、弓、佩剑、扇与书卷均按角色区分；完整提示词见`docs/art/2026-10-22-historical-portraits.md`。
