# 三国行旅 H5 · 2.0.0 城邑与兵战

地图60座城邑改为立体城墙、城门、楼阁与阴影组成的小城图标，重镇与水埠有不同外观。保留旗帜、兵力、搜索、缩放、键盘选择和手机触控。

在城内打开“队伍”，先通过“军务 · 募兵”招募预备兵，再为每名角色选择步兵、枪兵、骑兵、弓兵或弩兵并分配0—1000名士兵。候补也能配兵，卸兵归还预备队。角色与所部共用棋格和行动，棋盘显示随行士兵、兵种、人数和士气条；受伤会消耗兵力并降低部队战力，治疗不会补回已损失士兵。战斗、途中与未处理事件期间不可调整配兵，切磋保持单人。

每个战斗单位独立拥有0—120士气，默认80，攻击、防御与速度乘以`0.5 + 士气/160`：80时100%、120时125%。普通攻击命中士气+3，受伤按伤害比例降低士气（每次最多20），守势恢复10；低于10时每轮末流失当前士兵10%，向上取整，恢复至10即可停止。永久六维、最大体力、移动距离与射程不随士气变化。原全局资源在战斗页标为“行旅士气”。

## 帮工、武学操作与主角攻城

城内帮工可输入1—72个五日块（5—360日），确认前显示总天数、军需及铜钱；每实际帮工一日仍得军需1、铜钱20。剩余历法不足时不执行。途中商旅的单次帮忙仍属于独立路遇事件。

战斗指令持续显示主角已装配武学，标明等待主角行动、冷却及目标限制。轮到主角后选择武学，再点击合法格或使用目标格下拉框施展；距离不足时可先移动。

地图“军务 · 募兵 / 攻城”或城内“军务 / 攻城”开放招募、围城和驻军调拨。招募以100人为单位，每人2铜钱，整编1日；随行预备兵上限20000。先前往目标城，再输入出兵人数并检视军令，显示守军、军需及3—10日围城时间，确认后按天下战争规则自动结算真实伤亡。失败余兵退回预备队，胜利余兵驻守城市，归属、太守和存档同步更新。NPC可以反攻，主角驻军不会自行出征；可在自己的城池补入或提取驻军，提兵须留守至少2000人。个人投奔关系与主角军府分开保存。

专项验证为`python scripts/verify_city_work.py`、`python scripts/verify_equipped_martials.py`、`python scripts/verify_player_military.py`，用`H5_URL`指定隔离开发服务；离线包验收为`python scripts/verify_work_martials_conquest_package.py`，另用`H5_PACKAGE_URL`指定本地包服务。三种屏幕尺寸覆盖预览不扣费、真实UI施展、兵力守恒、占领/冷却刷新恢复。旧0.7验收脚本定位的“帮工1日”入口已由新帮工专项取代。

## 0.7 群雄逐城

NPC势力现在会随着游戏日推进自主出征：从本城扣除兵力，沿现有道路集结、行军和围城，胜者占领城市，败者携幸存兵力沿路撤退。36座城的归属与守军实时保存；地图显示旗号、兵力和在外军队，“天下局势”可筛选城池、查看军队详情及最近50条天下战报。打开面板、查看人物和买卖商品不会推进战争。

历史背景决定各势力的登场年代，之后允许动态争夺。16个势力的初始布局根据现有地图节点编排，并非完整汉末疆域复原。每城仍以5000人为基础，每月补员50、上限20000；动态世界建立后，出征和实际战斗决定减员，不再重复套用未来固定历史减员。军队出征须保留本城至少2000人，单次最多征调60%，攻城结果与伤亡使用独立保存的随机状态。

城市易主后，府署、守军管理者、人物驻地、相遇与邀请门槛同步更新；出征人物不能在旧城同时被拜访，已同行人物保留在玩家队伍。普通士兵仍不可邀请，士兵长在役80、待聘60可邀请。玩家可继续个人行旅、跑商与五人战棋，也可通过军务招兵攻城。

旧档从当前年月建立天下快照，保留原有铜钱、货物、关系、成长、队伍及行程，不追溯演算此前战争；首次接入会显示可关闭的提示。若天下数据损坏，先备份原档并暂停战争，玩家可明确选择“重建天下局势（保留人物与行旅）”恢复。

## 既有地方军府与人物

36座城各有自己的守军，初始基础5000人，由当地太守/主事与士兵长共同管理。每月补员50人，上限20000；旧档接入时保留此前历史战乱节点按游戏比例整编的快照。具体人数与变化幅度是玩法参数，并非史实兵力统计。城内“府署名册”显示当前人数、共同管理者、单兵与部队合计战力。普通士兵不能邀请；士兵长在役亲密80、待聘60可邀请，入队后指挥岗位显示缺任，守军仍留在原城。

普通士兵按部队计算：每人生命10、攻击3、防御1、六维各10，部队合计随有效人数相加；伤亡降低有效人数与攻击、防御、六维。速度11、移动3格和射程1—2格保持兵种水平。真实战斗规则支持合并部队；NPC攻城使用独立战略结算。

新增夏侯惇、夏侯渊、曹仁、曹休、刘表、刘璋、张鲁、马腾、卑弥呼、公孙瓒、袁绍、刘虞、张燕十三位人物及独立立绘，夏侯惇另有伤目前版本，194年起切换伤目外观；连同普通士兵、士兵长，共新增16张透明全身图。十二位历史人物按游戏编排的年月与城邑开放相遇，卑弥呼仅供人物志查看，暂不开放相遇或招募。新增角色仍沿用五人出战和独立成长。

人物资料现有124个身份（包括72个驻城军士资料条目，普通士兵条目代表守军），可按姓名、城市和类别筛选。未同行军士、地方官员、孙坚孙策和山贼可正确显示自己的详情；只读人物不会显示邀请承诺。旧档按原日期推导守军，不重置铜钱、库存、关系、成长、阵容与行程。

## 跑商与事件

抵达后点击“进入城池”，在市集输入数量买卖粟米、粗布、盐、铁器、陶器、茶叶、药材、丝绸、米酒和皮革。初始600铜钱、40格货舱，铜钱与军需独立；货舱记录均摊成本，账本保留最近20笔交易和累计收益。36城有各自特产与需求，价格和库存每7个游戏日换一批；商人收价为当日卖价的90%，同城立即倒卖会亏损。北海运盐至太原、成都运丝绸至武威是可探索的路线。商品价格与产地是游戏参数，并非真实汉末逐城物价复原。

商旅可能传来某城某商品涨跌20%的消息，消息确实修正买卖价，持续30日，同城同货新消息替换旧消息。消息簿注明截止日期；远途抵达前可能过期。陆路与山道可能遭遇狼群，可绕行或进行五人战棋；狼群有四足小人与爪牙攻击，胜利给予出战成员基础经验30及20铜钱，候补不分经验。1日帮工也可获得20铜钱，铜钱归零仍能继续。

首批7幅CG用于雨阻、商旅/行情、流民、渡口、匪徒、狼群、人物见闻。CG确认阶段、行情、库存、货舱与战斗上下文自动保存，刷新不重抽、不重复结算。旧档只在缺少经济字段时补入初始铜钱，不覆盖已有资源、成长、亲密度与阵容。

## 本地运行

### 双击启动的 Windows 本地版

打包后的目录是 `release/三国行旅-本地版/`。双击其中的 **启动游戏.cmd**，浏览器会自动打开游戏；游玩时保留启动窗口，结束后关闭窗口即可。可以把整个文件夹复制到其他 Windows 10/11 64 位电脑，无需安装 Node.js、npm 或 Python，也无需联网。

不要直接打开源码目录的 `index.html` 或包内的 `www/index.html`；前者是 Vite/TypeScript 源码入口，后者需要通过本机服务加载游戏资源。存档保存在当前浏览器的 `http://127.0.0.1:18743` 下，与开发版存档分开；复制文件夹不会自动迁移浏览器存档。

修改源码后，先关闭本地版启动窗口，再使用 Node.js 22 或更新版本在 Windows 上重新生成本地包：

```powershell
npm run build:local
npm run test:local
```

## Cloudflare Workers 部署

当前仓库提供 `wrangler.jsonc`，直接部署 Vite 构建生成的 `dist` 静态资源，无需 Cloudflare Vite 插件或服务端入口。

连接 GitHub 后，在 Cloudflare Workers 构建设置中填写：

- 构建命令：`npm run build`
- 部署命令：`npx wrangler deploy`
- 根目录：仓库根目录
- Worker 名称：`threekingdoms`（与 `wrangler.jsonc` 中的 `name` 一致）

将配置提交并推送到 Cloudflare 监听的分支后，重新触发部署。若修改 Worker 名称，也应同步修改配置中的 `name`。

本地可先运行 `npm run build`，再用 Node.js 22 或更新版本运行 `npx wrangler deploy --dry-run` 做部署预检；预检不会发布网站。实际部署需要 Cloudflare 登录授权。

此配置适用于 Workers；如果创建的是 Pages 项目，则设置构建命令 `npm run build`、输出目录 `dist`，无需填写 Workers 部署命令。

## 当前玩法

1. 新游戏从184年春季开始，先等概率抽取13个州级区域之一，再随机抽取该州内的落脚点。目前共16处：司隶河南尹、豫州颍川/汝南、兖州东郡、徐州东海、青州北海、冀州巨鹿、幽州涿郡、并州太原、凉州武威、益州蜀郡、荆州南阳/长沙、扬州吴郡/丹阳、交趾刺史部南海。点击“踏上逃难路”开始；出生地区保存在存档中，刷新与重试不改变，重新开局重新抽取。
2. 世界地图按城邑实际方位与历史交通走廊概绘，包含60座城邑、92条双向通路。点击城邑或目的地列表，可预览途经地点、道路类型与预计天数，再选择启程。普通道、水路、山道按距离和不同速度估算耗时。
3. 每次可自填1—30日赶路，提供1/3/7/15日快捷选择；逐日判定20%事件概率，遇事或抵达立即暂停，不自动补完剩余日程。途中可能遇到商旅、流民、雨阻、渡口、匪患、人物消息、市场行情或陆路山狼。事件先展示CG，再选择后续行动。先处理事件再继续；可迎战匪患，也有不花军需的绕路或等候选项。旅行进度、随机状态与未处理事件自动保存，刷新不会重抽。出生地保留不变，到达后更新当前位置。
4. 最多五人出战（含固定主角），其余同行成员候补。每名出战队员每轮各有一次移动和一次攻击或守势；移动后仍可攻击有效射程内的敌人。敌我双方按速度从高到低混合行动，同速按出场顺序；每轮每人行动一次，倒地自动跳过。右侧行动队列支持翻页查看全员。“结束行动”让当前队员守势并推进到下一人。
5. 城内可处理当地事务、查看地方官员、帮工休整或明确选择长期安居。清路、帮助村民各耗1日，护送耗3日；完成护送后返回地图自行选下一站，不再自动跳过数年。游戏使用每月30日的简化历法，旅行和停留推动184、190、194、200等时间节点。
6. 地域人物见闻按年份、地区与存活情况开放，遇见后只解锁对应军府；200年起三方均可选择，也可以保持无所属。主事名称随年代与本局寿命变化，无存活合格人选时显示军府机构。确认投奔后回到原行程，不会自动触发战斗。
7. 城内“寻访人物”可与开放相遇的角色建立关系：资料目录共198个身份，包括3名初始角色、134名可招募人物、60个只读守军条目和只读卑弥呼。交谈+8、帮忙+10均免费，分享粮食+12耗1军需；每次互动停留1日，同人当天不能重复互动。普通人物亲密度达到60、士兵长及其他受雇人物达到80后免费邀请进入候补，未成年、已经离世或不符地点条件的人不能邀请。“所有人物行踪”显示当前动态驻地或在外出征等行踪，历史活动窗口另作参考，只读条目明确提示限制。
8. “队伍”中可上阵、下阵或满员替换，候补保留等级、经验与属性；只有本场出战成员获得胜利经验和政略补给。战斗及未处理的途中事件期间阵容锁定，战斗中可查看真实体力和装备。所有同行成员都能分配技能点。旧存档补齐亲密度和默认三人出战名单，原有成长保留。

长期邀请历史人物同行属于架空剧情，邀请曹、孙、刘不会自动投奔其阵营；已同行者同样在本局浮动卒年离世，成长和关系转入纪念档案，已学武学保留。所有既有画像保留。早期人物活动窗口与史料边界见`docs/art/2026-10-23-recruitment-history.md`，1.0生卒与后期人物依据见`docs/research/2026-10-24-generation-existing-lifespans.md`和`docs/research/2026-10-24-generation-new-people.md`。

城邑坐标、黄河东北入海、长江及秦岭等山川为历史地理示意；武关道、蜀道与岭南通道参考考据，但未复原所有驿站、古河道与精细州郡边界。道路30公里/日、水路50公里/日、山道20公里/日为游戏参数，暂不区分顺逆流。地图可以拖动、缩放和复位；手机也可从按州分类的列表选择目的地。资料来源与近似范围见 `docs/art/2026-10-23-world-geography.md`。

地图和棋盘采用明亮的草木、沙土、浅蓝水域配色。日期决定春夏秋冬，历史阶段调整底色；格线、移动提示、攻击目标仍独立可辨。旧存档保留资源和成长，缺少日历的已选阵营存档补到200年，未选阵营存档补到184年。

## 流民成长与战棋地形

姜垣以菜刀开局，阿满与陈达使用拳脚。护送任务中获得短刀、木枪和猎弓；木枪射程 1–2 格，猎弓射程 2–3 格且不能贴身射击。开局为三名流民，后续招募者使用各自兵器与造型；文官的书卷等用于游戏号令与援护能力。

出战成员独立积累经验（候补不分）：伏击胜利基础经验各 30 点，路线战斗基础经验各 45 点，倒地同伴也能获得胜利经验。初始 1 级、上限 10 级；从当前等级升级需要 `20 + 10 × (等级 - 1)` 点经验，溢出经验保留。每升一级增加 2 最大体力，每两级增加 1 攻击。当前两场战斗可从 1 级升至 3 级，结算显示升级结果；等级、经验和已领奖记录自动保存，失败与重试不发经验，刷新结局不会再次领奖。旧版存档会补齐三人的初始成长数据。

棋盘扩大为 **16×10**。点击“全图”查看完整战场，“放大”查看局部，“归位”定位选中队员；鼠标与触摸均可拖动，鼠标滚轮也可切换缩放。右侧行动队列可选择当前队员或查看所有敌我详情，移动范围用绿点标记，有效攻击目标用红框标记。

- 巨石、倒车和断墙：阻挡移动与攻击视线。
- 河道：不能直接穿越，通过木桥通行；不阻挡射击。
- 树林：每格消耗 2 点移动力，受到远程伤害减少 1，伤害最低为 1。
- 道路和木桥：每格消耗 1 点移动力。

敌军也会绕过障碍，按自身移动力移动后攻击。点击地形可查看说明。手机建议横屏，放大后棋格更便于点击。


## 六维培养、闪避与绝招

每升一级获得 **3 点技能点**，所有同行成员分别培养。每项属性初始为 10，每项上限 30；保留原有等级基础成长，以下加成按超过初始值的投入计算：

| 属性增加 1 点 | 实际能力变化 |
| --- | --- |
| 统率 | 防御 +1，命中伤害最低为 1 |
| 武力 | 攻击 +1 |
| 智力 | 闪避率 +2%，上限 40% |
| 政略 | 每次首次胜利，全队合计额外补给 +1 |
| 魅力 | 该角色的胜利经验 +5%，按整数百分比计算后向下取整 |
| 魄力 | 最大体力 +2 |

点击角色面板的“成长”，或路线/胜利/结尾中的成长入口，可以切换角色并分配。加减按钮修改草稿，实时预览能力，确认后一次保存；取消不扣点，切换角色保留本次草稿。战斗中仅可查看。旧存档会按已有等级补发未分配点数，保留原等级、经验、路线与奖励标记。

每人当前拥有一个绝招，每场战斗限用一次：

- **姜垣 · 绝处逢生**：体力不高于最大体力的一半时可用，回复最大体力的 30%（向上取整、不超过上限），本回合下一击攻击提高 50%。
- **普通角色 · 拼命**：消耗最大体力的 20%（向上取整，至少 1），且不能把自己扣至倒地；本回合下一击攻击提高 50%。普通敌人在半血以下且能够攻击时也可能使用。

发动绝招不消耗移动或攻击机会，但本回合攻击/守势后无法发动。强化不能叠加，攻击后或本方回合结束时消失；闪避也会消耗攻击机会与本次强化，不返还绝招次数或体力。闪避时目标保留守势。骰点使用关卡固定初始种子与本场随机状态，重试相同操作可复现。

战斗右侧显示所选角色的防御、闪避和绝招条件。绝招按钮位于队员名单下方、守势按钮上方；棋子金色三角和角色面板“攻击强化”标明下一击强化，消息区显示闪避与敌方拼命。
