# 三国行旅 H5 Demo

这是一个以流民视角进入三国乱世的叙事 RPG H5 原型。当前切片先验证核心循环：共同序章、点击探索、曹操/孙权/刘备路线选择，以及一场小型战术战斗。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173` 即可游玩。

## 常用命令

```powershell
npm test
npm run build
```

## 当前玩法

1. 在序章面板点击“踏上逃难路”。
2. 点击旧驿道完成伏击，再到枯井村补给，前往临水镇。
3. 进入路线选择，从曹操、孙权、刘备中选择一条路线。
4. 每回合三名队员各有一次移动和一次攻击或守势；移动后仍可攻击有效射程内的敌人。所有队员完成行动后，敌军统一行动。“结束回合”会让其余队员守势。
5. 战斗结束后查看路线影响下的收束文本。

当前画面使用 Phaser 绘制的几何素材与像素主角头像，方便先验证交互和节奏；正式美术素材可以在玩法稳定后替换。中文文字使用独立的高清渲染与字形留白，避免缩放后裁字。

主角暂定名为姜垣。地图和战斗中会显示姜垣的角色面板。战斗面板实时显示体力、攻击、移动、所属阵营与行动状态，点击头像可选中主角。手机竖屏时面板移至棋盘下方。

曹方增加补给与姜垣攻击，孙方增加士气与队伍移动距离，刘方增加士气、体力与守势减伤。路线奖励会累加到已有资源上。

地图和路线进度会自动保存在当前浏览器中。战斗中刷新页面，会从当前战斗开局重新开始；战败后也可以直接重试当前战斗。手机建议横屏游玩。

## 浏览器验证

启动开发服务器后，在已安装 Playwright 和 Chromium 的 Python 环境中运行：

```powershell
python scripts/verify_h5.py
python scripts/verify_tactical_ui.py
```

脚本通过鼠标或触摸操作完成三条路线的序章、伏击、补给、路线战斗、结局和重新开局，同时检查战败重试、刷新恢复、角色面板数据、中文文字边界与窄屏布局。截图保存在本地 `artifacts/` 目录。使用其他 Vite 端口时，可设置 `H5_URL` 环境变量。


## 流民成长与战棋地形

姜垣以菜刀开局，阿满与陈达使用拳脚。选择阵营后的任务才获得短刀、木枪和猎弓；木枪射程 1–2 格，猎弓射程 2–3 格且不能贴身射击。当前切片保持三名流民，不会开局配备骑兵或重装士卒。

三人独立积累经验：伏击胜利各获 30 点，路线战斗各获 45 点，倒地同伴也能获得胜利经验。初始 1 级、上限 10 级；从当前等级升级需要 `20 + 10 × (等级 - 1)` 点经验，溢出经验保留。每升一级增加 2 最大体力，每两级增加 1 攻击。当前两场战斗可从 1 级升至 3 级，结算显示升级结果；等级、经验和已领奖记录自动保存，失败与重试不发经验，刷新结局不会再次领奖。旧版存档会补齐三人的初始成长数据。

棋盘扩大为 **16×10**。点击“全图”查看完整战场，“放大”查看局部，“归位”定位选中队员；鼠标与触摸均可拖动，鼠标滚轮也可切换缩放。右侧同行名单可切换队员，移动范围用绿点标记，有效攻击目标用红框标记。

- 巨石、倒车和断墙：阻挡移动与攻击视线。
- 河道：不能直接穿越，通过木桥通行；不阻挡射击。
- 树林：每格消耗 2 点移动力，受到远程伤害减少 1，伤害最低为 1。
- 道路和木桥：每格消耗 1 点移动力。

敌军也会绕过障碍，按自身移动力移动后攻击。点击地形可查看说明。手机建议横屏，放大后棋格更便于点击。
