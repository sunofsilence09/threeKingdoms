# 0.2 世界地理数据说明

## 范围与来源使用

`src/game/world.ts` 提供34座可旅行城邑、42条双向交通走廊，覆盖184年13州部，保留16个出生ID。经纬度与道路折点为独立手工概绘，表达相对位置及交通走廊，不是古城遗址的测绘坐标。未下载、复制或改绘CHGIS或其他受限GIS底图；未使用现代省界或清代1820年边界冒充东汉地图。

本表使用184年的州郡名；政权疆界、城池占领、州郡随年份迁治暂未模拟。`prefecture` 是郡国/尹层级文字，用于地方资料检索，不能据此推定有可考官员。出生地区落点代表当地城邑，出生ID始终不变。

## 交通与距离

- 关中—宛：长安、蓝田、商洛、武关、丹水谷地至南阳盆地，以山道概绘。
- 关中—蜀：长安沿渭水向西到褒斜北口，经秦岭至南郑；南郑沿金牛道走廊经广元、剑阁、绵阳至成都。没有直接从长安穿山连成都。
- 凉州：姑臧—允吾—狄道—长安，经河西东口、金城和陇山走廊概绘；中间河流渡点和郡县未全部设为独立城。
- 巴荆：江州沿长江、三峡、夷陵方向到江陵，不画横贯湖北山地的直线水路。
- 荆扬：江陵沿长江到洞庭口，再接湘水至临湘；向东经江夏、鄱阳湖接南昌，再沿长江和青弋江走廊接宛陵。水路折点只表达河流整体走向，未逐一复原古河道、湖岸、支流入口或季节水位。
- 岭南：临湘—郴—番禺走南岭陆路山道；泉陵—广信走潇水、萌渚岭与贺江方向的复合山道走廊；广信—番禺沿西江。未把跨分水岭段标成连续水运。
- 沿途短渡、上下船和城港接驳折入路段类型与耗时；广陵—吴、广陵—宛陵道路包括长江渡口接驳，`road` 不表示全程无需渡河。

每条边按端点与`via`折线逐段计算球面距离，普通道路30公里/日、水路50公里/日、山道20公里/日，整边向上取整且至少1日。它们是游戏参数。未区分顺逆流、风向、坡度或实际战乱封路；上下行基础耗时相同。寻路使用Dijkstra最短耗时，不是最短直线距离。相同起终点返回0日、空路段；不存在的ID返回null，直接调用`cityAt`查询未知ID抛错。

## 考据与疑义

1. [中国社会科学网《探幽秦楚古道》](https://www.cssn.cn/lsx/slcz/202211/t20221111_5563675.shtml)：长安—蓝田—商洛—武关—宛交通走廊依据。本文叙述跨越多个时代，本版仅采用秦汉已存在的总体走廊，不套用唐代驿站表。
2. [北京大学孙华《蜀道考古的若干问题》](https://archaeology.pku.edu.cn/info/1030/5722.htm)：采用褒斜—金牛体系，资料同时提醒道路在汉代曾有阻断与改道；本版不声称184年每段均能无阻通行。页面首次拉取超时，搜索索引后成功读到原文。[北大机构库记录](https://ir.pku.edu.cn/handle/20.500.11897/773870)可核书目信息。
3. [山东省情资料相关条目](https://shandong-chorography.org/database/a/section/3/article/10/)：前序考据确认北海治剧、东郡治濮阳；本轮重试超时，沿用已查资料。
4. [复旦TGAZ巨鹿郡条目](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_87045)：只参照其书目注记所引《清一统志》关于后汉移治廮陶的信息。该条目主体时间是西汉，其点坐标不是东汉郡治，未复制。廮陶概点另据[宁晋地方政务文章](https://www.thepaper.cn/newsDetail_forward_9358884)关于县城西南古城方向取定。
5. [永靖县政府《允吾古城遗址》](https://www.gsyongjing.gov.cn/yjx/zmyj/yjjy/YZYJ/art/2022/art_6cfa3576928547698714ef8c78df319e.html)：搜索索引载有永靖境内与异说，页面正文提取不完整；仅据地域范围放置概点，不声称确认遗址。
6. [中国社会科学网《“广信”文化：关于家乡历史的建构》](https://www.cssn.cn/ztzl/jzz/rwln/wh/tswh/202209/t20220923_5541295.shtml)：用于识别梧州、封开古广信位置争议。故不标“交趾刺史部治所”，只作苍梧郡城邑节点。

访问日期：2026-10-23。web-access浏览器前检未配置默认浏览器，本次采用已授权的web只读工具读取公开资料，未改变用户浏览器偏好。

## 验证

`npm test -- src/game/world.test.ts`：6项通过，覆盖16出生ID、13州部、全图连通、1,156对起终点、双向对称、路径连续性、关键走廊、地理方位、近远行程与水陆耗时量级。首次空契约实现运行确认4项失败后再补实现。历史合理性测试不能代替完整史料复原。

## 地域人物见闻
相遇剧情是游戏演绎，采用年代和区域门控，不是某日人物精确行踪复原。184年颍川从五月开放曹方消息、南阳从六月开放孙坚消息，涿地开放刘备；后续关东讨董/兖州/许地、徐州与江东分别设置时段。江东孙策消息从195年开放，避免194年提前出现，依据《三国志》卷46裴注引《江表传》“兴平二年”渡江记载：https://zh.wikisource.org/wiki/三國志/卷46 。月份窗口为游戏剧情安排，不能当作史书确证任期或精确驻地。
