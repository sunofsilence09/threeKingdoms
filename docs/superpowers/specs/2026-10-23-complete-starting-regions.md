# 完整州级出生区域

用户要求：增加扬州、荆州等地区，州级范围要完整。

沿用已经确认的184年随机出生设计，补齐东汉末年的13个州级区域：司隶、豫州、兖州、徐州、青州、冀州、幽州、并州、凉州、益州、荆州、扬州、交趾刺史部。

司隶属于校尉部，纳入与州并列的抽签范围。南方区域在184年开局使用“交趾刺史部”，不提前使用203年之后的正式州名。

范围依据：[华东师范大学学报关于两汉十三州的讨论](https://xbzs.ecnu.edu.cn/CN/html/2018-4-50.htm)；名称年代依据：[复旦大学/哈佛大学CHGIS交趾条目](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_30277)。地方道路、村落及相遇故事为游戏虚构。

共16个出生地点。保留原颍川、汝南、南阳、涿郡的存档ID；荆州新增长沙，扬州提供吴郡和丹阳，其余新增区域各提供一处郡级地点。每个地点具备序章、道路、村落、营地及地图起点。

抽签改为先等概率抽州、再等概率抽州内地点。这样每个州概率为1/13，不因某州地点较多而提高该州权重。出生地区仍保持存档稳定，不因扩容重抽旧进度。新增地点不自动生成阵营相遇记录。

实施与验收：先写13州覆盖和分层抽签测试并观察失败；补齐数据和抽签方法；移除浏览器测试中“四个出生点”的硬编码；遍历16点验证序章、地图、地点遭遇和刷新恢复，检查手机长地名；执行完整单测、构建并同步本地包。
