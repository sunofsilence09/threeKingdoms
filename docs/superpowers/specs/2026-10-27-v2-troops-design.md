# 2.0.0 城邑与兵战

用户已于2026-10-27确认本方案。

地图保留当前SVG投影和交互，每座城市使用原创等距城墙、城门、屋顶、侧面与投影组成的小城图标，保留所属旗、兵力、选中和当前位置提示。

角色在城内队伍面板从随行预备兵配兵，可选步兵、枪兵、骑兵、弓兵、弩兵。每人最多1000兵，配兵立即扣预备兵，卸兵归还。每个角色和士兵共享棋格、行动和目标；士兵提供额外体力与攻防，伤亡真实消耗，人物切磋保持单人。无兵角色仍可正常战斗。

每个战斗单位拥有独立0—120士气，默认80。攻击、防御、速度按0.5+士气/160修正，80恰好100%，120为125%。不改变人物六维、永久成长和最大体力。受伤降士气、攻击提升士气，守势恢复10。士气低于10的部队每轮末流失当前士兵10%（向上取整），士兵归零后角色仍能战斗。士气恢复至10即可停止流失。

五兵种各有耗士气技能：步兵坚阵、枪兵突刺、骑兵冲锋、弓兵齐射、弩兵强射。强射本次攻击射程+2。技能占本次攻击行动，移动后可用；无合法目标、士气不足、未轮到时不扣费。扣费后按当前士气计算技能效果。敌军同样受士气规则约束并可使用兵战技。

新增配兵配置和战斗部队字段使用严格校验。旧档缺省无配兵、80士气，旧战斗可继续。战后与撤退写回存活士兵，仅结算一次；刷新保持伤亡、士气和行动。保留既有全局士气资源，但界面明确其为行旅士气。

验证覆盖配兵守恒、非法输入、伤亡结算、80基准及上下变化、10阈值、守势恢复、强射范围/视线/扣费、其他兵战技、旧档恢复及地图交互。运行全量Vitest、TypeScript/Vite生产构建和本地包服务测试，浏览器检查地图、配兵、战斗、刷新和手机布局。
