# 姜垣流民开局、大棋盘与障碍地形（已确认，含等级系统）

## 用户确定的方向

- 主角暂定名为姜垣，替换游戏中主角的“旅人”称呼。
- 开局是流民，使用拳脚、菜刀等简陋武器，正规兵种随剧情与装备逐渐出现。
- 棋盘比上一稿的 10×6 更大，并加入有实际规则的障碍。
- 取消上一稿开局重步兵、轻骑兵与双方各五单位的配置。

## 棋盘方案比较

- 推荐 16×10，共 160 格，是当前 6×4 的约 6.7 倍。提供全图和局部两档缩放、拖动及归位按钮。
- 保守 12×8，共 96 格，界面改动较少，但纵深较小。
- 20×12，共 240 格，更适合之后的大规模战斗；目前三人开局容易产生过多赶路回合。

## 身份、武器与成长

序章保持姜垣、阿满、陈达三人，不增加正规士卒。暂定姜垣用菜刀，阿满和陈达以拳脚开局。界面显示“流民·菜刀”或“流民·拳脚”，不直接称为刀盾兵、枪兵或骑兵。

序章敌人为持简陋兵器的拦路山贼。通过障碍、局部战线和敌方配置控制难度，不让空手队员正面对抗整队正规军。

成长顺序为：流民求生 → 获得短刀、木枪、猎弓等装备 → 通过投军、训练或招募出现刀盾兵、枪兵、弓兵 → 后续剧情具备马匹和补给条件后才出现骑兵。当前 demo 只实现序章简陋武器与投靠阵营后第一次基础装备提升；正规编制、招募和骑兵系统留给后续剧情。

装备统一配置名称、体力、攻击、移动和最小/最大射程；敌我共用规则。保留现有路线加成。姜垣的内部单位 ID 保留 traveler，显示名称改为姜垣。

## 地形与关卡

序章与路线战斗均使用 16×10。出生点接近局部交战区，距首批敌人约两个移动回合；不用从最左端一直追到最右端。新增空间用于绕行、掩护和后续增援。

| 地形 | 移动 | 战斗作用 |
| --- | --- | --- |
| 空地、道路 | 正常通行 | 常规战斗 |
| 巨石、倒车、断墙 | 不可进入或穿越 | 阻挡移动和远程视线 |
| 河道 | 不可进入或穿越 | 通过桥梁形成渡口 |
| 桥梁 | 正常通行 | 构成狭窄通路 |
| 树林 | 每格消耗 2 点移动力 | 受到远程攻击时伤害减少 1，至少受到 1 点伤害 |

射程按横纵格数相加计算，同时检查视线；不能隔着巨石、倒车或断墙射击。河道不阻挡视线。近战不能穿越障碍攻击。

旧驿道用倒车、巨石和树林组织两条绕行路径；路线战斗用断墙、树林、河道与桥梁组织中央通路和侧翼。固定布局保证重试可复现，验证出生点合法且至少存在一条交战路径。

移动范围采用带地形成本的寻路；敌军遵守相同的移动成本、障碍和视线规则，按自身移动能力接近合法攻击位置，并可移动后攻击，不再固定每回合只走一格。

## 显示与交互

战场使用独立视口，面板和按钮固定在战场之外。提供全图概览与局部放大，通过鼠标滚轮或缩放按钮切换；鼠标与触摸均可拖动，拖动释放不会误点格子。提供归位按钮，选中屏幕外队员时自动定位。

显示单位名、武器、血量和行动状态。选中队员展示移动范围与有效攻击目标；点击地形显示通行与掩护说明。角色面板与战斗按钮不遮挡棋格，保留手机竖屏下方角色面板。

## 验收

- 主角对话、棋子、队伍列表、头像说明和选中按钮均使用姜垣。
- 序章三人只使用拳脚、菜刀；路线战斗才出现第一次基础装备提升。
- 棋盘 16×10，障碍真实阻挡寻路，河道仅桥梁可通行。
- 树林成本、掩护、远程射程与视线有实际效果，提示与规则一致。
- 回归覆盖绕障、窄路占格、移动成本、不可达目标、视线、行动限制、路线加成与关卡连通性。
- 通过 npm test、npm run build，以及三条路线的浏览器鼠标/触摸流程与桌面/手机布局检查。
- 保留工作区已有未提交改动。
