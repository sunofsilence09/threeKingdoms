## 目标与交付

从0.3.0升级至0.4.0「商旅见闻」。串起“选择目的地→自定赶路日数→事件CG→处理见闻或战斗→抵达并进城→买卖货物→依据行情去下一城”的完整玩法。保留184开局、13州部34城、五人阵容、亲密度、历史相遇和旧存档。

本次采用三个相连模块推进：旅行/事件演出，城市/经济，人物/美术。最终一起集成并验收，不只交付菜单或图片。

## 方案取舍

## 一、自由赶路日程

- 途中提供“本次赶路天数”数字输入，允许1—30日整数，默认3日并记住上次有效选择；旁边有1、3、7、15日快捷按钮。
- 点击后按日推进，而非一次跳过。遇到事件、抵达目的地或到达游戏历法上限时立即停下，显示本次实际推进天数。
- 遇事后的剩余天数不自动执行。处理完事件后玩家再次点赶路，避免刚关闭CG就误触下一事件。
- 每个可触发事件的旅行日，概率从16%调到20%。事件按条件池抽取；增加事件类型时保持总概率20%，不叠加成多次独立判定。
- 当日到达目的地优先结算到达，不再在抵达后插入途中事件。输入空值、小数、负数、超过30均给出明确提示，不消耗时间或改变随机数。
- 原有随机种子继续随每个实际旅行日保存，刷新不能重抽；默认参数保持3日，原调用和旧档能迁移。

## 二、先看CG，再处理事件

- 首批制作7幅独立横版位图CG：雨阻道路、路遇商旅、流民求助、渡口停航、匪徒拦路、山狼袭击、人物见闻。商品行情消息复用商旅CG；城市市集使用商旅图作为横幅。
- 图片延续现有半写实历史插画风格，横向约16:9，明亮而有气氛；无现代物件、文字、界面和水印。画面中的流民衣装参考现有姜垣、阿满、陈达；不用其他名将画像冒充身份。
- 新事件先保存事件与未读CG状态，打开独立CG弹层。显示画面、事件标题、简短导语和“继续”按钮；按继续才保存已读状态并显示后续选择。
- CG展示期间地图、赶路、买卖和改阵不可操作；不自动结算奖励或开始战斗。小屏使用完整可见的图片与可滚动文字，关闭/键盘操作不能绕过CG后丢失事件。
- 在CG前、CG后、战斗中刷新都回到相同事件阶段，不重抽、不重复弹已确认的CG、不重复发奖。旧档待处理事件补为未读CG。
- 图片加载失败时显示标题与文字并允许继续，事件仍可完成；CG按需加载，序章不等待所有大图。

## 三、进城与跑商

### 城市入口

- 在当前位置提供“进入城池”。只有无进行中旅程、无战斗、无待处理事件时可进入。新开局所在城与后续抵达的34城均可进入。
- 城内是独立的可交互城市面板，顶部显示城名、日期、铜钱、货舱；包含“市集”“行囊/账本”，并可访问当地人物与官员，退出后回到当前位置的世界地图。
- 保留原有城中事务快捷入口，不改变官员史料或强制选择阵营。进城本身不扣时间；货物交易不推进日期。

### 货币与商品

- 新增铜钱，初始600；与军需分开。旧档仅在缺少经济字段时补一次600铜钱、空货舱，保留原资源与成长。
- 首批8种商品，单位价格是游戏参数，不是汉末史实货币换算：

| 商品 | 基础买价（铜钱/份） |
| --- | ---: |
| 粟米 | 12 |
| 粗布 | 24 |
| 盐 | 20 |
| 铁器 | 60 |
| 陶器 | 28 |
| 茶叶 | 36 |
| 药材 | 32 |
| 丝绸 | 90 |

- 初始货舱容量40份，每份占1格；不与军需混用。库存按商品ID保存数量与总购入成本，支持均摊成本、已实现盈亏；全部卖完清零该商品成本。
- 购买/出售均可输入正整数数量，提供1、5、最大快捷选择，点击前显示总价、货舱余量、市场库存；不足铜钱、超容量、持货不足等均不可成交，不允许负余额、负库存或不安全整数。
- 市集同时显示商人卖价（玩家买入）与商人收价（玩家卖出）。收价固定为当前买价的90%向下取整，最低1，避免同城原价倒卖获利。
- 各城都有全部8类货物，产地商品基础库存80、其他商品30，每7个游戏日刷新一轮。买入减少库存，卖出增加库存，重复开面板/读档不刷新库存；相同城市同一周期的初始价格和库存确定一致。
- 铜钱归零仍可做既有帮工：每1日帮工在原军需+1基础上增加20铜钱；不会要求玩家重开。安居一月/一年不额外按天发铜钱。

### 城市差价

- 使用34城独立经济记录，按游戏产地设定配置商品修正，再加小幅城市差异与每7日的确定性波动。城市与商品ID固定，不能因UI排序改变价格。
- 产地/需求修正取0.65—1.50；城市偏移±8%，周期偏移±10%。这些是玩法近似，界面写“本地特产/需求”而非声称真实汉代逐城物价。
- 盐在沿海城、丝绸在成都及江东节点、药材在山地节点等作为游戏特产；至少提供并验证两条扣除10%买卖差仍可盈利的跨城路线。
- 行囊显示持货、均价、当前城出售估值、预计盈亏和累计已实现收益。最近20笔交易记录成交地点、日期、商品、数量与金额，便于核对。

## 四、行情消息与野兽

### 行情消息

- 新增“市价风声”事件，绑定明确的城市、商品、涨/跌幅（20%）、起止日期和原因文案，例如某城急需药材或新货到港。
- 消息产生时即把价格修正写入经济状态；CG和选择只控制演出，不通过重复读消息再次加价。涨跌同时影响该城对应商品的买卖价。
- 消息默认持续30日，过期自动按游戏日期失效；同城同商品的新消息替换旧消息，不能无限叠乘。界面和消息簿标明截止日期，抵达时以当前有效价格为准。
- 消息只指向34城内有效节点，货物必须来自8种商品。主要指向本趟目的地，其他城消息作为后续跑商参考；远途不保证在有效期内抵达。
- 提供“记下消息，继续行程”，无需花军需。城市和行囊可查看最近消息，已过期消息保留提示但不影响现价。

### 山狼袭击

- 在陆路和山道事件池增加山狼，水路不刷陆生狼群；先看独立野兽CG，再选择迎战或绕行。
- 迎战进入现有五人战棋，但敌人使用狼群名称、四足模型、爪牙攻击与对应能力，不以山贼小人冒充。狼是敌方单位，不加入人类招募目录。
- 狼群数量随1—5人阵容调整，至少3只、最多5只；复用乡道地形并验证合法站位、行动队列与所有出战兵器。
- 获胜：出战者基础经验30、铜钱20，整备1日后回原行程；倒地出战者仍拿经验，候补不拿。战败/撤退与绕行均耽搁3日、士气−1，无胜利奖励，不删除持货。
- 保留途中匪患流程，匪患奖励仍按原规则；本版不扩展货物被抢、永久死亡、狩猎材料或装备打造。
