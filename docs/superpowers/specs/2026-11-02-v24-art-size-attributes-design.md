## 百分制六维

1. 新规则下六维有效值为整数1—100，普通主角基础约50，已有10—18天赋映射为50—90，保留各人的强弱差异；新增人物也使用相同尺度。界面显示真实有效值，不做仅界面乘倍数。
2. 新有效值=旧天赋×5 + 已培养点数 + 羁绊加成，最终封顶100。已培养点数为原培养账目减10，范围0—20；每个技能点继续增加1分培养。既有技能点、配点账目和每段羁绊+2保留，不清零，不重复发放。
3. 新分配必须同时满足可用技能点、每项培养额度和有效值100上限；已到100时不能继续消耗技能点。旧档因新上限而超出的培养/羁绊账目保留，实际六维只取100，界面解释封顶。
4. 战斗、闪避、体力、战后补给、经验、领兵将领修正统一使用新尺度。以50为常人基准、每5分相当于旧制1分重新校准贡献，保持基础天赋战力大致接续；避免直接把大数代入旧的减10公式造成人人高闪避和补给暴涨。培养面板明确实际效果步进。
5. 统率/武力的领兵贡献也按相同尺度归一后计算，士气和人数另行作用；六维上限不限制全军汇总属性、总兵力或战斗伤害。
6. 新增独立属性规则版本3。已保存的1/2版战斗继续原体力、攻防、士气、随机数和结算；战斗结束后下一场才采用新规则。人物详情、成长预览、切磋老师、敌军和奖励必须使用对应战斗版本，不能显示新版而实战沿用另一套。
