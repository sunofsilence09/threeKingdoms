# 2.3.0 实施计划

依据已批准的设计：../specs/2026-11-02-v2-3-troops-history-design.md。

## 全局约束
- 主角已有0—1000兵，复用预备兵与战损账目；纯人物切磋不携兵。
- 新战斗统率/武力/存活兵数参与攻防，兵团伤害折算统一；旧快照原样续战。
- 184—280年约30项事件，史实与演义分别标注；跨日期只触发一次，旧档补为已读，无追发奖励。
- 讨董、官渡、赤壁、夷陵支线明确地点/窗口/成本/耗时/奖励，不能复活人物或强制改变天下归属。
- 补董白、卢植、皇甫嵩三名人物与透明立绘，已有张辽、高顺、徐晃跳过。
- 保留既有工作区修改，不擅自提交、推送或覆盖运行中的旧版本。

## 任务
1. 领兵规则：先写失败测试，增加规则版本/将领快照/统一伤害折算/守军适配；同步详情与配兵入口，验证旧战斗。
2. 历史事件：逐条核对史料，先测日期/迁移/一次性/参与条件，再实现事件目录、持久化、统一时钟、地图入口与回顾面板。
3. 人物与图片：补三名人物全生命周期、天赋、武学和活动数据，核实来源，独立绘制三张PNG及提示记录。
4. 整合：升级版本及说明，复核各任务与全局约束，修复审查问题。
5. 验证交付：全量Vitest、构建、本地服务；桌面/手机真实UI与独立2.3.0离线包，记录结果与局限。

任务2与任务3为独立实现任务，按subagent-driven-development技能分派；主代理处理任务1及整合验证。共享文件写入需协调，无代理提交。
